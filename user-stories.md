## User Stories

**Historia 1:**
Como paciente, quiero pedir una cita con un fisioterapeuta para recibir tratamiento en el centro.

**Historia 2:**
Como paciente, quiero ver mi plan de ejercicios para seguir correctamente mi rehabilitación.

**Historia 3:**
Como paciente, quiero recibir recordatorios de citas para no olvidar mis sesiones.

**Historia 4:**
Como fisioterapeuta, quiero ver mi agenda diaria para organizar mis sesiones y mis tiempos.

**Historia 5:**
Como fisioterapeuta, quiero añadir notas de progreso del paciente.

**Historia 6:**
Como gerente, quiero gestionar los turnos del personal para organizar el trabajo del centro.
